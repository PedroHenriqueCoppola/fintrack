# Referência visual

Telas desenhadas para o Fintrack. Não edite estes arquivos: eles são a referência que o agente compara com o código.

- `dark/`: todas as telas no tema escuro (padrão).
- `light/`: dashboard, analysis, goals e manage-modal no tema claro.
- `html/`: as mesmas telas em HTML estático com o CSS real, em px (divida por 10 para rem). Abra no navegador. Os arquivos `*.light.html` são a versão clara.

As regras estão em `docs/design-system.md`. O mapa de qual tela pertence a qual módulo está na seção 9 dele.
